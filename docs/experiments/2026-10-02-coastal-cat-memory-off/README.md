## 质量与证据

沿用旧报告四项：主体建模与细节；原场景材质、光照与环境动态；动画、运动与连接逻辑；代码结构、资源处理与故障恢复。四项同等考虑，不给伪精确百分制总分。价格、耗时、瞬时镜头遮挡不用于质量名次。

- **Sol**：海面层次、反光、泡沫与日落更丰富，猫与车细节完整，基础几何/材质共享较好。轮胎外半径0.453却用0.445计算，轮距偏差约1.80%；系统减少动画时仍播放；图形中断后错误层仍为`display:none`，看不到刷新提示。
- **Astra**：角色比例和车辆关系清楚，轮转方向与半径计算一致；减少动画时停播，图形中断提示可见；材质172个，可继续共用优化，未提供日落切换。
- 两组原HTML都无需外部运行请求，正常检查无页面/着色器错误。暂停冻结轮子、海面、鸟、云与围巾，恢复、调速、切换镜头、拖动与缩放均有效。
- 两组都有七只真正运动、拍翼的鸟。默认手机视口在部分时刻会被前景棕榈遮住，此现象单列，不用一个截帧决定视觉质量。
