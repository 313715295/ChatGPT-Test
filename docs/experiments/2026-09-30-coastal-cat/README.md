## 时间与费用口径

原任务开始到完成的墙钟用时包含安装、排队、检查、失败重试和工具等待。本次追加评估不计入原任务。原七组耗时相加约108分26秒，并行窗口约26分33秒；后补两组合计16分07秒，并行窗口约10分41秒。两批之间的间隔不算作模型执行时间，任务耗时之和与并行窗口不能混用。

模型用量按唯一模型响应去重，分别累计输入、缓存输入和输出，再与累计记录及本地会话数据库核对。模型响应次数不是工具次数。`input_tokens`已包含缓存输入；`reasoning_output_tokens`已包含在输出中，不能额外计费。九组缓存写入记录均为0，单次输入未超过272K，按标准长度价计算。

`费用 = ((输入 − 缓存输入) × 未缓存输入价 + 缓存输入 × 缓存价 + 输出 × 输出价) / 1,000,000`

- Astra Standard：每百万Token未缓存输入$10、缓存$1、输出$50。
- Sol Standard：每百万Token未缓存输入$2、缓存$0.10、输出$10。
- 原七组折算$11.695496，后补两组$0.426736，九组合计 **$12.122232**；不等于账户账单或实际额度扣减。
- 定价是2026-09-30查阅并在追加时重新核对的官方快照，见 [价格参数](data/pricing.json)、[站内费用依据](https://313715295.github.io/ChatGPT-Test/experiments/2026-09-30-coastal-cat/references/pricing-notes.html)及[GitHub文字说明](references/pricing-notes.md)。

## 验证与实际限制

统一电脑：Chrome、NVIDIA RTX 4070 Laptop GPU / D3D11。桌面1280×720和窄屏390×844。检查离线运行、运动状态推进、路程与轮转、暂停/恢复、调速、三镜头、键盘、拖动/缩放、减少动画偏好、主体有限坐标及WebGL上下文恢复。逐项结果公开，08的方向/滚动关系与减少动画偏好缺项已明确记录；正常打开网页不等于全部检查通过。见[证据索引](evidence/README.md)和[08/09独立记录](https://313715295.github.io/ChatGPT-Test/experiments/2026-09-30-coastal-cat/references/additional-verification.html)。

短窗口RAF频率接近本机165Hz刷新上限，仅作为本机观察，不支持通用性能排序。窄屏是桌面浏览器尺寸检查，并非真实手机GPU验收；没有验证长期负载、所有设备、生产级架构或物理仿真。02/06握把连接通过伸缩手臂实现，不是固定骨长IK；05/07机械动作更简化。08/09采用直线路线，09有较完整载物细节，但未单独转向。

上下文丢失/恢复使用真实WebGL测试扩展触发。01/02/06恢复后仍需页面重新加载；03/08由Three.js自动恢复，缺少自定义反馈且丢失期间继续模拟；04将不冒泡事件监听在window，原故障提示未触发；05可自动恢复但丢失期间继续模拟；07停止模拟并恢复后继续；09停止模拟，底层恢复后仍保持暂停和刷新提示。03/08水面顶点变化未重算法线，04每3帧更新。见[恢复实测记录](https://313715295.github.io/ChatGPT-Test/experiments/2026-09-30-coastal-cat/references/context-recovery.html)。

原07有一次约4分36秒失败的浏览器检查，后续重试通过；这影响原交付时间，不直接证明成品错误。原03最终交付时没有完成画面验收；08的原浏览器预览入口受策略限制，也未完成画面验证。本次补测已确认两者可运行，同时揭示08的运动问题。09原任务做了实际桌面/窄屏和离线、交互检查，本次仍独立核对。补测时间没有加回原任务耗时。
