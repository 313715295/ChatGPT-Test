# 验证证据索引

JSON保留观测值与检查结果，移除了私人机器路径。截图为实际网页和诊断副本画面。

- `browser-verification.json`：原成品运行、运动、暂停、调速、视角、离线、短窗口RAF与图形设备。
- `extended-verification.json`：窄屏多视角、键盘、拖动/缩放、减少动画偏好、轮转增量检查。
- `studio-verification.json`：统一主体几何规模、有限坐标和视角；只用于主体观察。
- `birds-verification.json`：飞鸟位置、双翼姿态变化与数量。
- `context-recovery.json`：实际WebGL丢失/恢复前后状态与提示。
- `source-verification.json`：原场景逻辑源码哈希和报告行号。
- `code-quality-review.json` / `quality-ranking.json`：逐项评估与本轮排序，均为Codex观察式判断。
- `NN-default.png` / `NN-view*.png` / `NN-mobile*.png`：原场景；`NN-studio-*.png`：统一主体；`NN-context-restored.png`：恢复后的实际画面。
- `contact-*.jpg`：原七组静态对照；08/09另有逐组截图与统一主体图。
- `additional-verification.json`：08/09独立的原网页、交互、几何、飞鸟与图形恢复检查。
- `rolling-contact-verification.json`：08/09实际车轮、地面与接触点运动方向和滚动量。

本机短窗口频率不等于低端手机帧率。原会话聚合Token和耗时另见数据表，原聊天日志未公开。
