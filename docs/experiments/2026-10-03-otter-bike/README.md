## 先看质量与原作品

各配置择优代表为 **03 · Astra极高标准 > 06 · Sol极高标准 > 07 · Sol极高Fast**，只评价这三件具体代表。不是平均质量、全九次严格总榜或模型通用排名。

- **03 · Astra**：角色表情、河岸层次与黄昏/环境音/留影更完整；第三秒几何负担最高。开放河岸仍可交付良好，不把环岛当作质量门槛。
- **06 · Sol标准**：角色、编织前篮、包裹与完整环河骑行更精细；弧长查表与轮转外半径匹配；近景关节接缝和全景部分稀疏区域仍可改进。
- **07 · Sol Fast**：布料横向卷曲与连续形变尾巴较细腻，暖秋配色协调、绘制负担低；直线滚动路线、功能和环境细节较简，轮转计算半径造成约7.82%理论角速度偏差。

04有更多可选交互、08有连续尾巴且更轻、09肢体曲面更顺滑，取舍没有隐藏。每次的优势、不足与代码在报告中逐项列出。时间、费用和一次拍摄遮挡不参与质量名次；非盲评，不给伪精确百分制分数。
